# Speed Test
![screenshot](https://github.com/user-attachments/assets/f6638552-2bc6-49fe-9b2c-4a52451981f7)

Run internet speed tests directly from your Steam Deck Game Mode using Cloudflare's global network. Implemented using the same [testing methology](https://blog.cloudflare.com/how-does-cloudflares-speed-test-really-work/) used on https://speed.cloudflare.com.

## Installation

Install it via [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader)
